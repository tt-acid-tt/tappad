# Mytheria Visuals Menu

Client-side Fabric mod for Minecraft Java Edition 1.21.4.

## Features
- Opens and closes with **Right Shift**.
- Dark modern interface with custom rounded panels, cyan/purple accents and a small opening animation.
- Visuals, Interface and Profiles tabs.
- Four clickable demo toggles in the Visuals tab.
- Does not require installation on a multiplayer server.

## Build
Requires Java 21 and Gradle 8.10.2. Run:

```sh
gradle build
```

The mod JAR is generated in `build/libs/`.

## Install
1. Install Fabric Loader for Minecraft 1.21.4.
2. Install Fabric API for Minecraft 1.21.4.
3. Put `mytheria-visuals-menu-1.0.0.jar` in the Minecraft `mods` folder.
4. Launch the Fabric 1.21.4 profile.
5. Press Right Shift in the game.
