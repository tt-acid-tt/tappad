# NEURO Launcher

Минималистичный Android-лаунчер с тёмным оформлением, градиентным фоном и полупрозрачными карточками. Проект предназначен для быстрого доступа к выбранным приложениям.

## Возможности

- Добавление ярлыков установленных приложений через кнопку **+**.
- Запуск приложения нажатием на его ярлык.
- Удаление ярлыка долгим нажатием.
- Поиск по добавленным ярлыкам.
- Сохранение списка ярлыков на устройстве.

## Требования

- Android 8.0 (API 26) или новее для запуска приложения.
- Для автоматической сборки используется GitHub Actions.
- Локально устанавливать Android Studio не обязательно, если используешь сборку через GitHub Actions.

## Как получить APK

В репозитории уже настроен workflow **Build Android APK**.

1. Открой вкладку **Actions** репозитория.
2. Выбери workflow **Build Android APK**.
3. Нажми **Run workflow**, если ручной запуск доступен. Сборка также запускается при push в ветку `main` и при pull request в `main`.
4. Открой завершённый запуск workflow.
5. В разделе **Artifacts** скачай архив `NEURO-Launcher-APK`.
6. Распакуй архив: внутри должен находиться APK-файл сборки.
7. Перенеси APK на Android-телефон и открой его для установки. Если Android попросит разрешение на установку из этого источника, разреши его только для доверенного приложения, которым открываешь APK.

Если сборка завершилась с ошибкой, открой её в **Actions** и проверь журнал шага, отмеченного как failed.

## Как устроена сборка

Workflow из файла `.github/workflows/build-apk.yml` выполняет следующие шаги:

1. Получает содержимое репозитория.
2. Настраивает Java 17, Gradle 8.9 и Android SDK.
3. Подготавливает Android-проект из файлов репозитория, в том числе из ZIP-архива проекта, если он используется.
4. Запускает задачу `assembleDebug`.
5. Загружает полученный APK как артефакт GitHub Actions на 14 дней.

## Важно

- Артефакт GitHub Actions — это ZIP-архив для скачивания; его нужно распаковать, чтобы получить APK.
- Debug APK предназначен для установки и тестирования. Перед публичным распространением приложения настройте отдельную подписанную release-сборку.
- NEURO Launcher — самостоятельное приложение. Чтобы использовать его как домашний экран Android, при необходимости выберите его в системных настройках приложений по умолчанию.
