# NEURO Launcher

Минималистичный Android-лаунчер с тёмным градиентным фоном, стеклянными карточками и быстрым запуском приложений.

## Возможности
- Сетка быстрых ярлыков с кнопкой `+`.
- Выбор среди установленных приложений.
- Нажатие на ярлык открывает приложение.
- Долгое нажатие позволяет удалить ярлык.
- Поиск по добавленным ярлыкам.
- Список ярлыков сохраняется на устройстве.

## Как получить APK через GitHub
1. Создай новый репозиторий на GitHub.
2. Загрузи **все файлы и папки** этого проекта в корень репозитория.
3. Открой вкладку **Actions**. Если GitHub попросит включить Actions — включи.
4. Запусти workflow **Build Android APK** через **Run workflow**, либо дождись сборки после загрузки файлов в ветку `main`.
5. Открой завершённую сборку и скачай файл в разделе **Artifacts**: `NeuroLauncher-APK`.
6. Распакуй скачанный ZIP — внутри будет `app-debug.apk`. Перенеси его на телефон и установи.

## Требования
- Android 8.0 (API 26) или новее.
- Проект собирается GitHub Actions; локально устанавливать Android Studio не обязательно.

## Примечание
Это самостоятельный лаунчер-приложение. Оно не заменяет системный домашний экран автоматически: при желании можно выбрать его как приложение главного экрана в настройках Android.
